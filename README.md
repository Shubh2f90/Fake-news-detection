# Fake News Detection

## About the Project

This project focuses on identifying whether a news article is real or fake using Natural Language Processing (NLP) techniques.

The goal is to explore how machine learning and transformer-based models can be used for text classification tasks. The project is currently under development and includes work on data preprocessing, feature extraction, model evaluation, and API integration.

## Technologies Used

- Python
- FastAPI
- Pandas
- NumPy
- Scikit-learn
- BERT / RoBERTa
- Git & GitHub

## Project Workflow

1. Collect and prepare news datasets
2. Clean and preprocess text data
3. Convert text into machine-readable features
4. Train and evaluate classification models
5. Expose predictions through a FastAPI endpoint
